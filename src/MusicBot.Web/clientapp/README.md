# Musick arayüzü — by SertAy

React + TypeScript + Vite. Kaynak kod src/, bağımsız OBS sayfaları public/overlays/ altındadır.

- npm ci: bağımlılıklar
- npm start: geliştirme sunucusu
- npm run build: ../wwwroot çıktısı

Geliştirme sunucusu API'yi 127.0.0.1:3050 adresine yönlendirir. Ana ekran pages/Dashboard.tsx, genel görünüm Studio.css, temel bileşen stilleri App.css içindedir. wwwroot dosyaları elle düzenlenmez.

Alternatif tasarım depo kökündeki design/console-concept/ altında bağımsız tutulur. Uygulama tarafından içe aktarılmaz.
